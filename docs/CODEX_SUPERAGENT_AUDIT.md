# Existing SuperAgent backend audit

The highest-impact issues are unrestricted execution defaults, incomplete subprocess cleanup, and routing/history isolation bugs.
**Verification:** All 13 existing tests passed with external agent launches blocked and configuration/history redirected to temporary directories. Additional probes reproduced the failures noted below. No repository files changed. Real CLI/API integration remains unverified.
Estimates are engineering days for one developer, including focused regression tests; overlapping changes should share work.
